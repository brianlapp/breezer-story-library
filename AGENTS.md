# Breezer’s story library

This is a public repository and public Netlify website. Never add private/unapproved drafts or credentials. Samples must be marked `sample: true` in book.json. Do not rewrite supplied prose unless asked.

Use the existing static build. Add stories only under content/<story-slug>/book.json and numbered Markdown chapter files. No database, framework, or custom ChatGPT connector is needed.

Run npm test and npm run build before committing. Pushes to main publish through Netlify. Never claim ChatGPT’s ordinary GitHub app can write; use a manual Markdown upload or an explicitly authorized Codex commit/push.
